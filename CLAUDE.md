# SocialMedia

Multi-brand content pipeline built on Claude Code skills (brand-brief, content-coach,
post-writer, viral-hooks, post-grader, repurpose, post-scheduler).

## Brands

Each brand has its own folder under `brands/` with a `brand-brief.md`. Run brand-specific
skills (post-writer, content-coach, etc.) from inside that brand's folder so they pick up
the right brief:

- `brands/one-with-digital/`
- `brands/larry-wetherby/`
- `brands/johns-sanitation/`

## Working agreement: keep brand briefs alive

`brand-brief.md` is not a one-time form — treat every post as a chance to sharpen it.
After writing or grading a post for a brand:

- Add any new real story, win, or customer moment to that brand's **Story Vault**.
- If the post reveals a sharper **Customer** description or **Wedge opinion** than what's
  currently written, update it.
- If a post's tone lands especially well (or gets flagged as off), refine **Voice**.
- Fill in any placeholder/bracketed details as soon as the user gives specifics.

Don't ask permission for small factual updates to a brand's own brief (new story, filled-in
placeholder) — just make the edit and mention it. Ask first only if it changes the strategic
substance (CTA, wedge opinion, target customer).
